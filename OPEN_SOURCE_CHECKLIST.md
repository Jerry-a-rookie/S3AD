# Open-source release checklist

- [x] Include the core model, baseline adapters, and clean benchmark entry point.
- [x] Exclude robustness scripts and internal result-processing scripts.
- [x] Exclude paper drafts, review materials, and local datasets.
- [x] Include the benchmark datasets used by the clean experiments.
- [x] Add installation, dataset, and usage documentation.
- [ ] Add an appropriate open-source license.
- [ ] Verify redistribution terms for every included dataset.
- [ ] Run the clean benchmark in a fresh environment.
- [ ] Remove machine paths, internal comments, and anonymous-review information.
- [ ] Decide whether to release the robustness experiments after paper acceptance.
